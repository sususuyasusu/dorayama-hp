# Instagram投稿 → 公式HP「お知らせ」加工ルール

対象: 門仲どらやき どら山 總本鋪（東京・門前仲町のどらやき専門店）の Instagram @dorayama_jp の投稿。
1投稿につき1つの JSON ファイル `news_items/<code>.json` を書く（UTF-8・整形あり）。

## 出力する項目

```
{
  "code": "投稿コード（入力のまま）",
  "date": "YYYY-MM-DD（入力のまま）",
  "publish": true か false,
  "exclude_reason": "publish が false のときだけ。理由を短く",
  "category": "旬どら | 新商品 | 催事・出店 | メディア | 店舗のお知らせ | 開店までの歩み | その他",
  "title": "見出し（日本語・30字以内・絵文字なし・【】は使ってよい）",
  "body": ["本文の段落1", "段落2", "..."],
  "media": null または {"outlet": "媒体名（番組名・雑誌名・サイト名）", "kind": "テレビ|雑誌|新聞|ウェブ|ラジオ|その他", "date": "放送日・掲載日（分かる範囲。不明なら投稿日）", "summary": "どんな形で紹介されたか1文"},
  "en": {"title": "...", "summary": "1〜2文"},
  "zh": {"title": "...", "summary": "1〜2文（簡体字）"},
  "ko": {"title": "...", "summary": "1〜2文"}
}
```

## 文章の整え方（日本語）

- 見出しは中身が一目で分かる名詞句に。例:「8月の旬どら『くりくり和栗どら』」「エキュート上野に期間限定出店」「テレビ朝日『じゅん散歩』で紹介されました」
- 「門仲どらやき どら山です！」などの挨拶の決まり文句、ハッシュタグ、絵文字・顔文字・記号飾り（♪ ✨ など）は削る。
- 本文はです・ます調の落ち着いた文章に整える。投稿の事実（商品名・期間・場所・数量・内容）は残し、新しい事実を足さない。推測で日付や数字を補わない。
- 価格の「円」は「圓」に置き換える（例: 460円 → 460圓）。
- 「日本一」という表現は使わない（「日本一ふかふか」→「ふかふか」など、言い換えるか削る）。
- 電話番号は載せない。
- 浅草の店舗（浅草店・浅草の支店）には触れない。その一文を削る。投稿そのものが浅草店だけの話なら publish: false。
- 「プロフィールのリンクから」「DMで」などInstagram内でしか通じない案内は、「テイクイーツのご予約ページから」など一般的な表現にするか削る。
- 段落は1〜4個。1段落は長くても120字程度。

## publish: false にするもの

- 他店・他社のどらやきを食べた感想（2021年ごろの「◯◯のどら焼きをいただきました」）
- ハッシュタグだけ・本文がほぼ無い投稿
- 浅草店だけの話
- 個人的すぎる内容・今は意味をなさない告知（例: 「本日は定休日です」のような当日限りの一言）

ただし 2021〜2022年の「ロゴのスケッチ」「店舗の施工中」「明日開店します」などの開店準備の記録は、`開店までの歩み` として publish: true で残す（どら山の歴史として価値がある）。

## メディア掲載の判定

テレビ・雑誌・新聞・ウェブ記事・ラジオ・プレスリリース配信などで紹介された（予定を含む）投稿は category を `メディア` にし、`media` を必ず埋める。媒体名は投稿文にある名前をそのまま正確に書く（推測しない）。

## 翻訳（en / zh / ko）

- 日本語の見出しと本文の要点を、その言語の自然な文章で。summary は1〜2文。
- どらやきは英語 "dorayaki"、中国語「铜锣烧」、韓国語「도라야키」。店名は "Dorayama"（英・韓）/「哆啦山」は使わず "Dorayama（どら山）" とする（中国語も Dorayama 表記）。
- 価格は「460 yen」「460日元」「460엔」。
